# 채보 플랫폼 MVP 요구사항

사용자는 웹에서 MP3 한 개를 선택한다. 브라우저가 CDN에서 경량 채보 모델을 내려받아 실행하고, 채보 이미지를 표시하며 원본 MP3 다운로드를 제공한다.

## 실행 환경과 지원 범위

- 백엔드는 웹 화면, 브라우저 추론 모듈, 모델 다운로드 URL 목록을 제공한다.
- 프론트엔드는 선택한 MP3를 브라우저 메모리에서 읽고, 모델 다운로드와 음원 전처리·추론을 수행한다. 기본 실행 환경은 ONNX Runtime Web의 WASM CPU다.
- 모델 담당자는 같은 export의 ONNX 파일과 메타데이터를 CDN의 버전별 경로에 배포한다. 브라우저는 기본 설정의 `current.json`을 읽고 파일을 직접 받는다. 서버가 URL을 발급하는 배포에서는 `/api/model-manifest`를 지정한다.
- 최초 MVP의 입력 형식은 MP3다. 다운로드 대상은 사용자가 선택한 원본 MP3다.

## 백엔드 최소 요구사항

1. 프론트엔드 화면과 정적 파일을 제공한다.
2. `/inference/`에서 브라우저 추론용 JavaScript 모듈을 제공한다.
3. `GET /api/model-manifest`에서 모델 버전, 정밀도, 파일별 다운로드 URL을 반환한다.
4. 기본 모델 정보는 CDN의 `current.json`에서 조회한다. 환경 설정으로 다른 목록 URL이나 고정 버전 경로를 지정할 수 있다. 비공개 R2를 사용하는 배포는 기존 서명 URL 발급 코드를 사용한다.
5. 모델 다운로드 설정 또는 URL 발급에 실패하면 API 문서의 오류 응답을 반환한다.

## 프론트엔드 최소 요구사항

1. MP3 파일 한 개를 선택하고 채보를 시작하는 화면을 만든다.
2. 모델 준비, 채보 진행, 완료, 실패 상태를 표시한다. 처리 중에는 중복 실행을 막는다.
3. 제공된 브라우저 추론 모듈을 호출하고, 반환된 음표 정보를 바탕으로 채보를 SVG 등 이미지로 렌더링한다.
4. 선택한 원본 MP3의 다운로드를 브라우저 `Blob` URL로 제공한다. 사용이 끝난 객체 URL과 모델 세션을 해제한다.
5. 모델 다운로드나 추론이 실패하면 사용자가 파일 선택을 유지한 채 재시도할 수 있게 한다.

## 모델 담당 최소 요구사항

1. `config.json`, `tokenizer.json`, 인코더, 임베딩, 디코더 ONNX를 같은 버전으로 CDN에 배포한다.
2. 백엔드 담당자에게 버전 경로와 버전 ID, 정밀도를 전달한다. 비공개 R2라면 서명 URL 발급에 사용할 카탈로그를 제공한다.
3. `webscore_inference/web/`의 입력 전처리, 토큰 생성·해석, 음표 반환 인터페이스를 구현한다.

## 기술 스택

- **백엔드** — Python, FastAPI, Uvicorn으로 화면과 모델 다운로드 정보를 제공한다. [FastAPI 정적 파일 제공](https://fastapi.tiangolo.com/tutorial/static-files/)
- **프론트엔드** — HTML·CSS·JavaScript 또는 React·TypeScript를 사용한다. 빌드 결과는 FastAPI가 제공하고, 모델 실행은 `onnxruntime-web`과 기존 JavaScript 추론 패키지를 사용한다. [ONNX Runtime Web](https://onnxruntime.ai/docs/tutorials/web/)
- **음원과 결과 처리** — 브라우저에서 MP3를 디코딩하고 16kHz 모노로 전처리한다. 채보 이미지는 모델이 반환한 음표 정보로 생성하며, 원본 MP3는 브라우저 객체 URL로 다운로드한다. [브라우저 객체 URL](https://developer.mozilla.org/en-US/docs/Web/API/URL/createObjectURL_static)

## 완료 기준

- 백엔드에 로컬 모델 파일을 배치하지 않은 환경에서 모델 URL 목록을 받고, 브라우저가 CDN 모델을 로딩할 수 있다.
- MP3를 선택하면 브라우저에서 추론하고, 채보 이미지와 원본 MP3 다운로드를 제공한다.
- 모델 다운로드 또는 음원 처리에 실패하면 원인을 안내하고 재시도할 수 있다.
