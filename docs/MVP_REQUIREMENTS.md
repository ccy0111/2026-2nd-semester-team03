# 채보 플랫폼 MVP 요구사항

사용자는 음원 파일 하나를 제출하고, 처리 결과 화면에서 채보를 이미지로 확인하고 음원을 MP3로 다운로드할 수 있다.

## 실행 환경과 지원 범위

- 프론트엔드는 사용자 PC에서 구동 중인 로컬 백엔드에 음원을 전송한다. 로컬 백엔드는 팀이 준비한 채보 모델을 사용자 PC의 CPU에서 실행한다.
- 모델은 저장소 밖에서 제공된다. 백엔드는 제공받은 모델을 로컬에서 불러올 수 있어야 한다.
- MP3는 필수 지원 형식이다. 추가 음원 형식의 지원 범위는 모델 연동 시 확정한다.
- 다운로드 대상은 제출한 음원의 MP3 버전이다. 입력이 MP3이면 제출한 파일을 그대로 제공하고, 지원하는 다른 형식이면 MP3로 변환해 제공한다.

## 백엔드 최소 요구사항

1. 음원 파일 하나를 받아 지원 형식인지, 읽을 수 있는 파일인지 확인한다.
2. 음원을 모델 입력 형식에 맞게 준비하고 채보 모델을 CPU에서 실행한다.
3. 모델 결과를 화면에 표시할 수 있는 채보 이미지로 준비한다. 채보 이미지와 제출 음원의 MP3를 프론트엔드에 제공한다.
4. 지원하지 않는 형식, 읽을 수 없는 파일, 모델 실행이나 결과 생성 실패를 프론트엔드가 구분할 수 있도록 처리 결과를 반환한다.

## 프론트엔드 최소 요구사항

1. 지원 형식을 안내하고, 사용자가 음원 파일 하나를 선택해 제출할 수 있게 한다.
2. 처리 중 상태를 표시하고 중복 요청을 막기 위해 제출 버튼을 비활성화한다.
3. 처리가 끝나면 결과 화면에 채보 이미지를 표시하고, MP3 다운로드 버튼을 제공한다.
4. 처리에 실패하면 원인을 안내하고, 사용자가 파일을 다시 선택하거나 재시도할 수 있게 한다.

## 기술 스택

- **백엔드** — Python, FastAPI, Uvicorn으로 로컬 서버를 실행한다. 업로드는 FastAPI `UploadFile`과 `python-multipart`로 받고, 작업 파일은 로컬 임시 디렉터리에 저장한다. [FastAPI 파일 업로드](https://fastapi.tiangolo.com/tutorial/request-files/)
- **프론트엔드** — 단일 화면은 HTML·CSS·JavaScript로 구현하거나 TypeScript 및 React 같은 프론트엔드 도구를 사용해 구현할 수 있다. 빌드가 필요한 경우 브라우저에서 실행 가능한 정적 파일로 출력한다. FastAPI는 화면과 API를 같은 로컬 주소에서 제공하며, 어느 스택이든 [API 문서](API.md)의 요청·응답과 정적 파일 제공 규칙을 따른다. [React에서 TypeScript 사용하기](https://react.dev/learn/typescript)
- **모델 실행과 채보 이미지** — 제공 모델의 CPU 실행 환경을 사용한다. Python 버전은 모델 호환 범위에 맞추고, 채보 이미지 생성 도구는 모델 출력 형식을 확인한 뒤 정한다. 프론트엔드는 백엔드가 제공한 이미지를 `<img>`로 표시한다.
- **음원 변환** — 모델 입력 형식을 맞추거나 추가로 지원하는 음원을 MP3로 변환해야 할 때 FFmpeg를 사용한다. [FFmpeg 문서](https://ffmpeg.org/ffmpeg.html)

## 완료 기준

- 정상 MP3를 제출하면 사용자 PC의 CPU에서 채보가 실행되고, 결과 화면에 채보 이미지가 표시되며, 제출한 MP3를 다운로드할 수 있다.
- 추가로 지원하는 음원 형식이 있다면, 해당 음원을 제출해 채보 이미지를 확인하고 MP3로 다운로드할 수 있다.
- 지원하지 않는 파일을 제출하거나 처리 중 오류가 발생하면 화면에 안내가 표시되고, 다시 제출할 수 있다.
