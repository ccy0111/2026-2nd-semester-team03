# 채보 플랫폼 PRD

MP3를 브라우저에서 분석해 음표를 시각화하고, 연주·편곡에 활용할 채보 초안을 제공한다. MVP는 음원을 서버에 업로드하지 않는 처리 방식과 파일 선택부터 결과 확인까지의 흐름을 완성하는 데 집중한다.

## 사용자와 문제

음악 프로듀서, 작곡·편곡자, 연주자, 밴드·동아리 구성원이 주요 사용자다. 공식 악보가 없는 음악을 반복해서 듣고 음정과 악기별 파트를 직접 옮기는 데 드는 시간을 줄인다.

장기적으로 다악기 음원의 채보를 지향한다. 초기 모델은 피아노 중심 시운전 단계이며, 다악기 정확도와 실무 수준의 채보 품질은 별도 검증 대상이다.

## 사용자 흐름

1. 웹페이지에서 모델 준비 상태를 확인하고 MP3 한 개를 선택한다.
2. 채보를 시작하고 처리 진행률을 확인한다.
3. 결과 이미지를 확인하고 선택한 원본 MP3를 다운로드한다.
4. 실패하면 파일 선택을 유지한 채 재시도한다. 일부 구간이 누락되면 해당 사실을 확인할 수 있다.

## MVP 요구사항

| 항목 | 요구사항 |
| --- | --- |
| 입력 | MP3 한 개를 선택하고 처리 중 중복 실행을 막는다. |
| 로컬 처리 | 모델을 CDN에서 다운로드하고 음원 디코딩·전처리·추론을 브라우저에서 수행한다. 음원은 서버로 전송하지 않는다. |
| 상태 안내 | 모델 준비, 처리 진행, 완료, 실패를 표시한다. 누락된 구간이 있는 결과는 정상 완료와 구분한다. |
| 결과 | 추출한 음표를 SVG 등 이미지로 표시한다. 현재 UI의 표현 방식은 피아노롤이다. |
| 다운로드 | 사용자가 선택한 원본 MP3의 다운로드 링크를 제공한다. |
| 재시도 | 모델 준비 또는 음원 처리 실패 시 원인을 안내하고 재시도할 수 있게 한다. |

로그인, 클라우드 음원 저장, 악보 편집, MIDI 다운로드는 MVP 필수 범위에 포함하지 않는다. 모델과 실행 모듈 다운로드에 네트워크가 필요하므로 완전한 오프라인 사용은 보장하지 않는다.

## 완료 기준

- 서버에 모델 가중치를 두지 않고 브라우저가 CDN 모델을 로딩한다.
- 개발용 시간 제한을 해제하고, 선택한 MP3의 전체 구간을 처리해 결과 이미지와 원본 MP3 다운로드를 제공한다.
- 모델 로딩·음원 처리 오류에서 파일 선택을 유지하며 재시도할 수 있다.
- 복구 불가능한 청크가 있어도 다른 구간의 결과를 보존하고 누락 구간을 사용자에게 알린다.
- 실제 MP3와 배포 모델을 사용해 채보 품질, 처리 시간, 메모리 사용량을 확인한다. 수치 목표는 실측 후 정한다.

## 현재 구현 상태

파일 선택, Worker 기반 추론, 진행률, 피아노롤 표시는 구현되어 있다. 현재 `DEV_MAX_SECONDS = 20`으로 입력 앞부분만 처리한다. 원본 MP3 다운로드, 모델 준비 재시도 버튼, 청크 누락 안내는 미구현이다. 추론 코어가 생성하는 MIDI는 현재 UI에서 제공하지 않는다.
